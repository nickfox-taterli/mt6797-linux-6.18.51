MT6797 Fastboot reboot marker
============================

This board bring-up device writes MT6351 RTC_PDN1[13] before the system
restart handler resets the SoC. It does not perform the reset itself.

Required properties:
- compatible: "mediatek,mt6797-fastboot"
- mediatek,pwrap: phandle to the MT6797 PMIC wrapper providing the MT6351
  register map.

Use a separate device node. The MT6351 PMIC node is owned by the regulator
driver; two platform drivers cannot bind that node simultaneously.

Example:

fastboot-reboot {
	compatible = "mediatek,mt6797-fastboot";
	mediatek,pwrap = <&pwrap>;
};
